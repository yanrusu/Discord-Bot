# Discord 機器人 

一個 Discord 機器人，提供實時天氣資訊和空氣品質指數查詢服務。

## 專案架構

- **Discord.py** - Discord 機器人
- **Selenium** - 網頁自動化爬蟲
- **BeautifulSoup** - HTML 解析
- **Requests** - HTTP 請求

## 項目結構 
```
Discord-Bot/
├── bot.py                 # 主機器人邏輯和命令定義
├── searchweather.py       # 天氣爬蟲模組
└──  aqi.py                 # 空氣品質指數查詢模組
```

## 文件說明 

- **bot.py** - 主要的機器人邏輯，包含 Discord 事件處理和命令定義
- **searchweather.py** - 使用 Selenium 爬取中央氣象館資料，解析天氣資訊
- **aqi.py** - 調用環保署 API 來獲取空氣品質指數

### 核心文件

#### `bot.py` 主邏輯
負責 Discord 機器人的核心功能：
- **事件處理**：監聽機器人上線、重新連接等事件
- **命令定義**：
  - `!todayweather` - 即時查詢天氣資訊
  - `!reportweather` - 設定天氣報告頻道
  - `!getaqi` - 查詢空氣品質指數
- **定時任務**：每天自動發送天氣預報到指定頻道

#### `searchweather.py` 天氣資訊爬蟲
使用網頁爬蟲技術獲取天氣資料：
- **工具**：Selenium + BeautifulSoup
- **數據源**：中央氣象館官方網站
- **功能**：
  - 模擬瀏覽器訪問氣象網頁
  - 解析 HTML 結構提取降雨機率資訊
  - 根據降雨率分級返回天氣提示文案

#### `aqi.py` 空氣品質指數查詢
調用政府開放 API 獲取 AQI 數據：
- **API 源**：環保署 API（`data.moenv.gov.tw`）
- **功能**：
  - 使用 API 密鑰進行身份驗證
  - 返回實時空氣品質指數

## 命令列表 

| 命令 | 功能 | 說明 |
|------|------|------|
| `!todayweather` | 查詢今日天氣 | 獲取實時天氣預報和降雨機率 |
| `!reportweather` | 設定天氣報告頻道 | 設定機器人發送自動天氣報告的頻道 |
| `!getaqi` | 查詢空氣品質指數 | 取得最近一個整點 AQI 數據 |

## 使用示例 

### 查詢天氣

在 Discord 群聊中輸入：

```
!todayweather
```

機器人將回覆：

```
降雨率 70% 以上，記得帶拖鞋
```

根據降雨機率，機器人會提供以下回覆之一：
- 降雨率 ≥ 70%：「降雨率 70% 以上，記得帶拖鞋」
- 降雨率 ≥ 50%：「降雨率 50% 以上，可能要帶拖鞋」
- 降雨率 ≥ 30%：「降雨率 30% 以上，應該不用帶鞋」
- 降雨率 < 30%：「今日不會下雨」

### 設定天氣報告頻道

在要接收自動天氣報告的頻道中輸入：

```
!reportweather
```

此後機器人會在每天早上 6:00 自動發送天氣預報到該頻道。

### 查詢空氣品質

```
!getaqi
```
返回最近整點的 AQI 指數。
